# 내친소 서비스 기획서

## 목적과 타겟
지인의 소개를 통해 상대를 만나고 싶은 성인과, 자신의 지인을 소개하고 싶은 주선자를 위한 초대형 소개팅 서비스다. 핵심 가치는 초대 관계로 계산한 관계 거리와 주선자의 소개글이다. 첫 운영 범위는 성인 테스트 참여자로 제한한다.

## 확정 규칙
- 초대한 사람과 초대받은 사람 사이가 1촌이다. 방향 없이 연결 수를 센다.
- 회원은 주선자이면서 소개받는 사람일 수 있다.
- 가입 시 초대자를 서버에서 확정하며 변경하지 않는다.
- 초대 코드는 만료 시간이 있는 1회용이다. 가입과 코드 사용 처리는 하나의 트랜잭션으로 처리한다.
- 최초 주선자는 운영자가 생성한다. 연결되지 않은 그룹끼리는 '연결된 초대 관계 없음'으로 표시한다.
- 주선자가 작성한 프로필은 당사자가 확인하고 공개를 승인해야 탐색에 나타난다.
- 매칭 요청과 수락은 당사자가 결정한다. 연락 정보는 양쪽이 수락한 뒤 공개한다.
- 기본 화면에는 촌수만 표시한다. 중간 연결자의 이름은 공개하지 않는다.

## 화면 구성
1. 홈: 서비스 가치, 이용 단계, 초대 가입 진입.
2. 둘러보기: 승인된 프로필 카드, 촌수 필터, 상세 소개, 매칭 요청.
3. 소개글 만들기: 지인의 특징 입력, AI 소개글 초안, 수정 및 당사자 승인 안내.
4. 마이페이지: 역할별 탭으로 분리. 인연찾기에서는 받은/보낸 매칭 요청과 내 프로필 공개 승인을 관리한다. 맺어주기에서는 소개하는 지인의 승인·공개 상태와 초대 코드를 관리한다. 한 회원이 두 역할을 모두 사용할 수 있으며 탭 전환은 권한 변경이 아니다.
5. 가입 화면(후속 구현): 초대 코드 검증, 계정 인증, 성인 확인, 프로필 공개 선택.

## AI 기능
입력: 당사자가 제공한 취미·성격·소개 포인트(20~1000자).
출력: 사실을 추가하지 않은 한국어 소개글 초안(약 150~300자).
가치: 주선자의 글쓰기 부담을 줄인다. 생성 결과는 자동 공개하지 않는다.
실패 처리: 필수값 누락과 길이 초과를 브라우저 및 서버에서 검사한다. API 오류와 시간 초과를 안내하고 입력을 보존한다. 처리 중에는 중복 요청을 막는다.
서버만 AI API 키를 사용한다. 입력에 연락처 등 불필요한 개인정보를 넣지 않도록 안내한다. 제공자와 모델은 연동 단계에서 확정한다.

## 구현 단계와 완료 기준
1. 현재: 기획·데이터 구조·가상 데이터 화면 시제품. 실제 회원/AI/매칭 서비스는 연결되지 않았다.
2. 인증·DB: 초대 코드 기반 가입, 로그인, 코드 원자적 소진, 접근 권한 검증.
3. 프로필: 초안 작성, 본인 확인, 공개 승인, 탐색과 관계 거리 계산.
4. 매칭: 요청·수락·거절·취소, 중복 방지, 수락 후 연락 정보 공유.
5. AI: Python API에서 실제 제공자 호출, 입력 검증, 오류·시간 제한·사용량 제한.
6. 배포: GitHub 및 Vercel 연결, 환경 변수 등록, 공개 URL에서 전체 흐름 검증.
7. 제출: README, 기획서, 데스크톱·모바일·AI 실제 동작 캡처, 코딩 도구 사용 기록.

## 검증 기준
만료/소진/없는 초대 코드 거부, 코드 동시 사용 시 단 한 건 가입, 타인 프로필 수정 거부, 미승인 프로필 비노출, 서버 계산 촌수 검증, 중복/본인 매칭 방지, 수락 전 연락처 비노출, AI 실패 후 재시도 가능, 390px/768px/1440px 레이아웃 확인.
