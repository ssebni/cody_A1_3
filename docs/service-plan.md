# 내친소 서비스 기획서

## 목적과 타겟
지인의 소개를 통해 상대를 만나고 싶은 성인과, 자신의 지인을 소개하고 싶은 주선자를 위한 초대형 소개팅 서비스다. 핵심 가치는 초대 관계로 계산한 관계 거리와 주선자의 소개글이다. 첫 운영 범위는 성인 테스트 참여자로 제한한다.

## 확정 규칙
- 초대한 사람과 초대받은 사람 사이가 1촌이다. 방향 없이 연결 수를 센다.
- 회원은 주선자이면서 소개받는 사람일 수 있다.
- 가입 시 초대자를 서버에서 확정하며 변경하지 않는다.
- 초대 코드는 만료 시간이 있는 1회용이다. 주선자는 최대 10자 메모로 초대를 구분하고, 가입이나 프로필 연결 전에는 초대를 삭제할 수 있다. 가입과 코드 사용 처리는 하나의 트랜잭션으로 처리한다.
- 최초 주선자는 운영자가 생성한다. 연결되지 않은 그룹끼리는 '연결된 초대 관계 없음'으로 표시한다.
- 주선자가 작성한 프로필은 당사자가 검토·직접 수정하고 공개를 승인해야 탐색에 나타난다.
- 프로필은 본명, 출생년월 기반 나이, 고향, 현재 거주지, 취미, 직업, 키, 종교, MBTI, 200자 소개글로 구성한다. 사진은 선택이며 최대 3장을 비공개 저장한다.
- 매칭 요청과 수락은 당사자가 결정한다. 연락 정보는 양쪽이 수락한 뒤 공개한다.
- 기본 화면에는 촌수만 표시한다. 중간 연결자의 이름은 공개하지 않는다.

## 화면 구성
1. 홈: 서비스 가치, 이용 단계, 초대 가입 진입. 로그인 후 메뉴별 독립 화면으로 이동한다.
2. 둘러보기: 승인된 프로필 카드, 촌수 필터, 상세 소개, 매칭 요청.
3. 소개글 만들기: 지인의 특징 입력, AI 소개글 초안, 수정 및 당사자 승인 안내.
4. 마이페이지: 역할별 탭으로 분리. 인연찾기에서는 받은/보낸 매칭 요청과 내 프로필 직접 수정·공개 승인을 관리한다. 맺어주기에서는 소개하는 지인의 승인·공개 상태와 초대 코드를 관리한다. 한 회원이 두 역할을 모두 사용할 수 있으며 탭 전환은 권한 변경이 아니다.
5. 가입 화면: 초대 코드 검증, 계정 인증, 성인 확인, 프로필 공개 선택.

## AI 기능
입력: 당사자가 제공한 취미·성격·소개 포인트(20~1000자).
출력: 사실을 추가하지 않은 한국어 소개글 초안(100~180자, 최대 200자).
가치: 주선자의 글쓰기 부담을 줄인다. 생성 결과는 자동 공개하지 않는다.
실패 처리: 필수값 누락과 길이 초과를 브라우저 및 서버에서 검사한다. API 오류와 시간 초과를 안내하고 입력을 보존한다. 처리 중에는 중복 요청을 막는다.
서버만 AI API 키를 사용한다. 입력에 연락처 등 불필요한 개인정보를 넣지 않도록 안내한다. 제공자는 Gemini Generate Content API를 사용하고 모델은 서버 환경 변수 GEMINI_MODEL로 지정한다. 실제 계정의 키와 모델 설정 후 실호출 검증이 필요하다.

## 구현 상태와 완료 기준
1. 구현: 초대 가입, 로그인, 서버 인증·권한 검사, 원자적 초대 소진, 프로필 저장·공개 승인, 매칭 요청·응답, 연락처 공유, 실제 AI 호출 코드.
2. 로컬 검증: API 자동 테스트, 로컬 PostgreSQL SQL·권한 테스트, 모의 응답 브라우저 테스트 및 390/768/1440px 화면 확인.
3. 외부 연결: 호스팅 Supabase 001~006 적용 완료. Gemini 환경 변수, 실제 AI 호출, Vercel 배포 URL 검증은 대기 중.
4. 제출 대기: 원격 동작 확인 후 README URL, 실제 AI·배포 화면 캡처, 원본 대화 증빙 보완.

## 이용 순서와 MVP 범위
초대 발급 → 지인 가입 → 주선자 소개 작성 → 본인 공개 승인 순서로 이용할 수 있다. 소개 작성은 가입 전에도 가능하며, 가입 후에는 원래 초대한 사람만 연결할 수 있다. 회원은 초대 코드 소유로 가입하며 이메일 소유 확인 메일은 구현하지 않았다. 성인 여부는 자가 확인한다. 처음에는 초대받은 성인 테스트 참여자만 사용한다.

AI 요청은 회원별 UTC 하루 10회, 15초 간격으로 제한하고 실패도 횟수에 포함한다. 프론트 요청은 최대 45초, AI 제공자 호출은 25초로 제한한다. 출력은 소개글 입력란에 옮겨 수정할 수 있으며 본인 승인 없이 공개하지 않는다.

## 검증 기준
만료/소진/없는 초대 코드 거부, 코드 동시 사용 시 단 한 건 가입, 타인 프로필 수정 거부, 미승인 프로필 비노출, 서버 계산 촌수 검증, 중복/본인 매칭 방지, 수락 전 연락처 비노출, AI 실패 후 재시도 가능, 390px/768px/1440px 레이아웃 확인.
